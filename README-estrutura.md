# Estrutura canônica do workspace do cliente

```text
adapta-cliente/
├── .claude/settings.json
├── .git/
├── 01_projeto/
├── 02_reunioes/
├── 03_documentos/
├── 04_fase-atual/
│   ├── fase.md
│   └── specs/
├── 05_entregas/
├── 06_notas/
├── AGENTS.md
├── CLAUDE.md
├── README.md
├── STATUS.md
└── changelog.md
```

As pastas vazias possuem `.gitkeep`. Elas são previstas para o ciclo de execução e não autorizam, por si só, criação de repositório, publicação ou integração externa.
